## Requirements and quick start

JDK 17 or newer (tested with JDK 25.0.1) and Maven 3.9+. No runtime dependencies and no Python are needed for the algorithms, experiment or PNG charts. JUnit 5.11.4 is the test dependency. The first Maven build needs access to Maven Central unless dependencies are already cached.

```shell
mvn clean verify
java -jar target/DAA_Assignment4-1.0.jar demo
java -jar target/DAA_Assignment4-1.0.jar experiment
```

`experiment` writes 540 individual measured runs to `results/results.csv`, medians/min/max to `results/summary.csv`, environment details and four PNG charts to `results/plots/`. It overwrites those generated results; use a different output directory to preserve the submitted measurements:

```shell
java -jar target/DAA_Assignment4-1.0.jar experiment results-new
java -jar target/DAA_Assignment4-1.0.jar plots results-new
mvn test
```

In IntelliJ IDEA: open `pom.xml` as a project, select JDK 17+, reload Maven, then run `org.example.Main`. For the experiment, set **Program arguments** to `experiment` and the working directory to the project root. Tests can be run from `src/test/java` or the Maven `test` lifecycle. Maven does not have to be installed separately when using IntelliJ's bundled Maven.

## Implementation and contracts

| Component | Implementation |
|---|---|
| `EditDistance` | Shared `int distance(String a, String b)` interface |
| `RecursiveEditDistance` | Direct last-character recursion, no memoization |
| `TableEditDistance` | Full bottom-up DP table |
| `TwoRowEditDistance` | Two rows; shorter string determines row width |
| `StringSearch` | Shared `List<Integer> search(String text, String pattern)` interface |
| `NaiveSearch` | Character-by-character comparison at each alignment |
| `KmpSearch` | Public `int[] lps(String p)`, forward-only text scan, overlap support |

All match indices are zero-based and increasing. Empty search patterns throw `IllegalArgumentException`; patterns longer than the text return an empty list. `lps("")` returns an empty array. Empty edit-distance strings work. Null arguments throw `NullPointerException`. Strings are compared **case-sensitively as UTF-16 code units**, as Java `charAt` does; no normalization is performed. Thus `Abylai Han` to `Abylai Khan` costs 2, while the lowercase versions cost 1.

Counters reset at each valid public algorithm call. Edit counters distinguish recursive invocations (including base cases), interior DP updates, character comparisons and allocated integer slots. Search comparisons include both successful and failed comparisons; LPS preprocessing is counted separately. Allocated slots exclude array headers, references, result lists and recursion stack memory. Instances hold mutable counters and should not be shared across threads.

## Tests and reproducibility

JUnit tests cover all assignment reference distances, LPS arrays and matches; empty strings/patterns; longer patterns; overlaps; 100 random short edit pairs; 100 random searches against both algorithms and Java `indexOf`; 100 LPS patterns checked against the definition; and exact small counter values and resets. All randomized checks use fixed seeds.

The experiment design was written before measurement in `EXPERIMENT_DESIGN.md`. Base seed: **25242026**. Each case has deterministic generation and a SHA-256 fingerprint. Re-running produces identical input fingerprints, answers and counters; elapsed times necessarily vary with the JVM and computer. Each case receives one warm-up invocation, followed by five measured invocations with rotated algorithm order; a shared small-input warm-up runs first. Generation, verification and output are outside timing. LPS construction, allocations and result construction are inside timing. The charts use medians, never a single selected timing.
